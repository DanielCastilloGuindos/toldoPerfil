# Toldo Perfil - Toldos y Pérgolas a Medida en Madrid

Toldo Perfil es un sitio web moderno desarrollado con Astro y adaptado para la venta, diseño, instalación y reparación de toldos, capotas, marquesinas, pérgolas y cerramientos de alta calidad en Velilla de San Antonio, Loeches y la Comunidad de Madrid.

## 🛠️ Tecnologías y Estructura
El proyecto está construido utilizando:
- **Astro**: Para el renderizado rápido en el servidor y prerenderizado de páginas estáticas.
- **Tailwind CSS**: Estructura de diseño moderna y semántica.
- **Drizzle ORM & SQLite**: Almacenamiento local de presupuestos y solicitudes.

## 📂 Archivos de AEO (Agentic Engine Optimization)
Para facilitar que los agentes de IA comprendan el proyecto y sus capacidades, este repositorio incluye:
- [llms.txt](/llms.txt) - Índice estructurado para consumo de modelos LLM.
- [AGENTS.md](/AGENTS.md) - Guía detallada de la arquitectura del código y convenciones para agentes de codificación.
- [skill.md](/skill.md) - Descripción formal de capacidades, entradas y límites del servicio de instalación de toldos.
- [agent-permissions.json](/agent-permissions.json) - Definición de políticas de acceso y límites para crawlers automáticos.
